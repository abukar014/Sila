### Account Creation Fix (RLS)
Added two RLS policies to Supabase (user confirmed they ran these):
```sql
create policy "providers_self_read" on providers for select to authenticated
  using (auth.uid() = user_id or auth.jwt() ->> 'email' = email);
create policy "providers_self_update" on providers for update to authenticated
  using (auth.jwt() ->> 'email' = email)
  with check (auth.jwt() ->> 'email' = email);
```
account.tsx now does UPDATE-first (by email, user_id null) before falling back to INSERT.
